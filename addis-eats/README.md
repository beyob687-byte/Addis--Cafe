# Addis Eats Menu App

A static React application built with Vite to display an authentic Ethiopian cuisine menu.

## Prerequisites

- Node.js installed on your machine.

## Setup and Run Locally

1. **Clone or navigate to the project directory:**
   ```bash
   cd addis-eats
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```

4. **View in Browser:**
   Open [http://localhost:5173](http://localhost:5173) in your web browser to view the app.

## Project Structure
- `src/App.jsx`: Main application component that defines the menu data and maps through it.
- `src/Header.jsx`: Header component for the app banner.
- `src/Dish.jsx`: Reusable card component to display individual menu items.
- `src/index.css`: Custom premium styling with vibrant colors and modern aesthetics.
